# Odyssey 70mm watcher — Praha Flora

Правярае раскладу Cinema City кожныя 20 хвілін і шле push у Telegram, калі:

- **з'явіўся новы сеанс** Odyssea ў фармаце 70mm (новы дзень / новы час);
- **вярнуліся месцы** на сеанс, які быў sold out (нехта здаў квіткі);
- (апцыянальна) засталося менш за N% месцаў.

Кіно: **Cinema City Praha Flora**, зала `IMAX VOLVO` — адзіны 70mm IMAX у Чэхіі
і адзін з трох ва ўсім ЕС.

---

## Адказ на галоўнае пытанне: дзе гэта круціцца?

**Не на тэлефоне.** iOS і Android забіваюць фонавыя працэсы праз некалькі хвілін —
надзейна апытваць сайт кожныя 15 хвілін з тэлефона немагчыма.

**І не абавязкова на кампе.** Скрыпт круціцца **бясплатна ў воблаку GitHub**,
а натыфікацыі прылятаюць **на тэлефон у Telegram**. Камп і тэлефон могуць быць
выключаныя. Гэта і ёсць варыянт «на тэлефоне» — толькі надзейны.

---

## Крок 1. Зрабіць Telegram-бота (2 хвіліны)

1. У Telegram знайдзі **@BotFather** → `/newbot`.
2. Прыдумай імя і username (мусіць сканчацца на `bot`, напр. `odyssey_flora_bot`).
3. BotFather дасць **токен** выгляду `1234567890:AAF...` — захавай.
4. Знайдзі свайго новага бота ў пошуку і націсні **Start** (без гэтага ён не зможа
   табе пісаць).
5. Даведайся свой `chat_id`: напішы **@userinfobot** → ён верне лічбу, напр. `123456789`.

## Крок 2. Стварыць рэпазіторый

1. Зайдзі на [github.com](https://github.com), зарэгіструйся (бясплатна).
2. **New repository** → назва `odyssey-watch` → **Private** → Create.
3. Загрузі файлы (кнопка *Add file → Upload files*) так, каб структура была:

```
odyssey-watch/
├── odyssey_watch.py
└── .github/
    └── workflows/
        └── watch.yml
```

> Каб зрабіць укладзеныя папкі праз вэб: *Add file → Create new file*, і ў полі
> імя ўпішы цалкам `.github/workflows/watch.yml` — GitHub сам створыць папкі.
> Змест скапіруй з файла `watch.yml`.

## Крок 3. Дадаць сакрэты

У рэпазіторыі: **Settings → Secrets and variables → Actions → New repository secret**

| Name | Value |
|---|---|
| `TELEGRAM_TOKEN` | токен ад BotFather |
| `TELEGRAM_CHAT_ID` | лічба ад @userinfobot |

## Крок 4. Запусціць

Укладка **Actions** → `odyssey-watch` → **Run workflow**.

Першы запуск прышле паведамленне «Вартаўнік запушчаны» са спісам бягучых сеансаў.
Далей — толькі калі нешта змянілася. Дадай бота ў замацаваныя чаты і ўключы
для яго гук.

---

## Пра што трэба ведаць

- **Cron у GitHub Actions не заўсёды дакладны.** Пры высокай нагрузцы запуск можа
  затрымацца на 5–20 хвілін. Для «злавіць вяртанне квітка» гэтага звычайна хапае,
  але калі трэба секунды — патрэбны платны VPS.
- **Рэпо мусіць быць публічным.** GitHub тарыфікуе кожны запуск мінімум як 1 хвіліну.
  Пры інтэрвале 20 хвілін гэта ≈ 2160 запускаў/месяц — а бясплатны ліміт для
  **прыватных** рэпо ўсяго 2000 хв/месяц. Для публічных Actions бясплатныя без ліміту.
  У рэпо няма нічога сакрэтнага: токен ляжыць у зашыфраваных Secrets, а `state.json` —
  проста спіс сеансаў.
- **Не рабі інтэрвал менш за 5 хвілін** — Cinema City можа забаніць па IP.
- Раскладу зараз апублікаваная толькі на ~2 тыдні наперад, таму новыя даты
  дадаюцца рэгулярна — скрыпт іх зловіць.

## Запуск на Windows (калі не хочаш GitHub)

```powershell
$env:TELEGRAM_TOKEN="сюды_токен"
$env:TELEGRAM_CHAT_ID="сюды_chat_id"
python odyssey_watch.py
```

Каб кожныя 15 хвілін: **Планировщик заданий** (Task Scheduler) → Create Task →
Triggers: *Repeat task every 15 minutes, indefinitely* → Actions: `python.exe`
з аргументам поўнага шляху да `odyssey_watch.py`. Мінус: камп мусіць быць уключаны.

## Налады (env-зменныя)

| Зменная | Дэфолт | Што робіць |
|---|---|---|
| `CINEMA_ID` | `1052` | Praha Flora. Chodov = `1056`, Nový Smíchov = `1031` |
| `FILM_QUERY` | `odys` | падрадок у назве фільма, ніжні рэгістр |
| `REQUIRE_ATTR` | `70-mm` | пакінь пустым, каб лавіць любы фармат |
| `DAYS_AHEAD` | `120` | на колькі дзён наперад глядзець |
| `LOW_SEATS_RATIO` | `0` | напр. `0.05` — алерт, калі засталося <5% месцаў |

## Як гэта працуе пад капотам

Публічны JSON API Cinema City (той самы, што выкарыстоўвае іх сайт):

```
GET /cz/data-api-service/v1/quickbook/10101/dates/in-cinema/1052/until/{дата}
GET /cz/data-api-service/v1/quickbook/10101/film-events/in-cinema/1052/at-date/{дата}
```

Другі эндпойнт вяртае для кожнага сеанса `soldOut` і `availabilityRatio`
(доля вольных месцаў) — адсюль і бярэцца дэтэкцыя вяртанняў.
Стан папярэдняй праверкі ляжыць у `state.json`.
